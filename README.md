# Soepdetective

Interactieve lessen bij de soepen van Good Soup, voor groep 5 t/m 8 (OBSH).
Nu online: **Wortelsoep**. Andere soepen volgen.

## Bestanden
- `index.html`: de hele website (opmaak, inhoud en spelletjes in één bestand)
- `img/`: alle illustraties
- `CNAME`: de domeinnaam (alleen als je een eigen domein koppelt)

## Inhoud aanpassen
Alle teksten van de les staan bovenaan het script in `index.html`, in het blok `const LES = { ... }`.
Tekst die per niveau verschilt staat als `{ g56: "...", g78: "..." }`.
